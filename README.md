## A little about me

I’m a developer based in **Hargeisa, Somaliland**, working across frontend products, backend systems, automation, Linux, delivery workflows, and security.

My centre of gravity is broader than a job title. I like taking a rough idea, making the problem clear, shaping an interface people can actually use, wiring the systems behind it, and leaving the whole thing more reliable than I found it. Security is an important part of how I think—not the only thing I build.

I’m currently studying Computer Science at the University of Hargeisa while building production-oriented projects, writing technical and personal notes, and sharpening the fundamentals behind good software.

## Selected work

### [Samaale General Trading Co.](https://samaale-general-trading.com) — bilingual commerce and logistics platform

Designed and shipped a production-grade English/Somali digital headquarters for a regional distributor. The platform turns a complex catalogue, branch network, logistics services, and procurement workflow into a clear path from discovery to inquiry.

`React` `TypeScript` `Tailwind CSS` `Cloudflare Workers` `Leaflet` `SEO` `Accessibility`

### [Gabay Keeper](https://github.com/guuly05/gabay-keeper) — preserving Somali oral poetry

A private digital archive for Somali oral poetry, with structured metadata, OCR for printed text, footnotes, filtering, and shareable visual exports. This is one of the projects closest to my heart because it connects engineering with cultural memory.

`React` `TypeScript` `Firebase` `Firestore` `Tesseract.js`

### [PurplePrint](https://github.com/guuly05/purpleprint) — private, offline-first Android writing

An Android Markdown editor that parses documents and exports PDFs entirely on-device. It has no internet permission because privacy is part of the product, not a line added at the end.

`Kotlin` `Jetpack Compose` `Material 3` `AST parsing` `PdfDocument`

### [Cyber Attack Monitoring Dashboard](https://github.com/guuly05/cyber-attack-monitoring-dashboard) — security intelligence in one workspace

A real-time investigation dashboard for IPs, domains, CVEs, threat feeds, and risk context. It keeps API keys on the server and gives analysts a faster way to move from an indicator to an informed next step.

`Next.js` `TypeScript` `TanStack Query` `Recharts` `Threat intelligence`

### [Full-Stack Portfolio Platform](https://www.guuleedmaxamuud.dev) — this website, built as a product

My portfolio is also a working application: case studies, a Markdown publishing system, route-aware SEO, protected contact, availability checks, calendar booking, Google Meet links, and a security-minded deployment model.

`React 19` `Vite` `TypeScript` `Markdown` `Cloudflare Turnstile` `Google Calendar`

## Security is still part of the story

My security work has taught me to look past the happy path: how authentication fails, where access boundaries become unclear, what an operator sees during an incident, and whether a fix will survive contact with the real system.

I work with vulnerability assessment, web and network testing, Linux hardening, secure coding, reporting, and security automation. My toolkit includes **Nmap, Burp Suite, Nessus, OpenVAS, Metasploit, Wireshark, Linux, Bash, and Python**, with working knowledge of **OWASP Top 10, CVSS, threat intelligence, and incident-minded investigation**.

That perspective now follows me into everyday software engineering: validate inputs, protect secrets, design clear boundaries, document decisions, and make the safer path the easier path.

## How I work

- Start with the real problem, not the most impressive technology.
- Make complicated things easier to understand—for users, teammates, and future me.
- Treat accessibility, documentation, performance, and security as part of the build.
- Prefer small, understandable systems that can be improved over time.
- Keep learning by building, reading documentation, studying fundamentals, and writing things down.
